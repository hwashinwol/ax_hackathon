# Corevia 관련 거래처 장려금 결재 서비스 (MVP)

`../hackathon_data`(하위 폴더 포함 전체)를 읽어 워크플로우 4단계를 실제로 돌리는 Flask + SQLite 서비스입니다.

```
pip install -r requirements.txt
python app.py            # http://127.0.0.1:5060
python -m unittest discover -s tests   # 3대 시나리오 통합 테스트
```

오른쪽 위에서 **접속 역할**(영업팀·재무팀·내부감시팀·품질팀·Masil)을 바꿔 가며 시연합니다. 점선 테두리 버튼이 현재 역할이 누를 차례인 버튼입니다. `시연 초기화`는 요청·결재·로그만 지우고 원천 데이터는 건드리지 않습니다.

## 시연 순서 (기준 거래처 D-011, 정산 2026-06)

| 단계 | 역할 | 동작 | 결과 (실제 데이터) |
|---|---|---|---|
| 1 | 영업팀 | 새 요청 → AI 매칭 실행 | D-024 90점 자동 그룹, D-037 76점 수동 검토 |
| 2 | 내부감시팀 | D-037 그룹 확정 | MATCHING 복귀 |
| 3 | 영업팀 | 실적 합산·리스크 검사 | 합산 23,324,352원 ≥ 2,000만, 장려금 3,888,097원 (16.7%) → 90일 초과 연체 29,202,840원으로 **PENDING** (시나리오 2) |
| 4 | 영업팀 → 재무팀 | 소명 제출 → 연체 회수 확인(또는 상계) | 재검사 후 AWAITING_APPROVAL |
| 5a | 재무팀 → 내부감시팀 | 승인 → 승인 | **PAID** (시나리오 1) |
| 5b | 재무팀 | CASH_SHORTAGE 거절 | AI가 Masil CH-04 크레딧 대안 제안 → 영업·재무 수락 → **CREDIT_SCHEDULED** → Masil 발주서 확인 시 CREDIT_SETTLED (시나리오 3) |

## 명세와 데이터의 차이

| 워크플로우 명세 | 실제 데이터 | 서비스 처리 |
|---|---|---|
| A대리점 D-001 · B쇼핑몰 D-002 (김○훈, 테헤란로 123, 계좌 123-456-789) | D-001 류민준, D-002 권도윤으로 서로 무관. 실제 관련 그룹은 D-011·D-024·D-037 (박상현) | 마스터·수금 이력에서 자동 탐지. D-001로 요청하면 관련 거래처 없이 기준 미달 |
| 연락처·IP 신호 | 컬럼 없음 | 매칭 화면에 '데이터 없음'으로 표시, 컬럼(`phone`, `registered_ip`)이 생기면 표시 대상 |
| `qc_claims_cv.internal_judgment = 악의적` | 필드 없음, 클레임은 C-고객 단위 | 필드가 생기면 3회 이상 규칙 자동 적용. 현재 보류 트리거는 90일 초과 연체 |
| 미수금 "이상 없음" | 그룹 90일 초과 연체 29,202,840원 | 연체를 보류 사유로 사용, 재무팀 회수 확인·상계로 해제 |
| 분기 3억 × 2% | 월 정산, 요율 10~17% | 월/분기 선택, 월 기준선 2,000만 예시(분기 ×3), 실제 요청 금액 사용 |
| `covenant_terms_ms.md`, `lc0001_payment_term_notice.md` | 미제공 | `fin_cash_daily_ms.covenant_min_krw`, CH-03(LC-0001) 회수율 하락으로 대체. 파일이 생기면 자동 인식 |
| `sc_purchase_orders_ms.csv` | 미제공 | CH-04 청구일 간격으로 다음 발주 추정. 파일이 생기면 PO 날짜 사용 |

규칙 파라미터(가중치·기준선·연체일수·크레딧 비율)는 `config.py`에 있습니다. 데이터에 근거가 없는 값이라 예시값입니다.

## 구조

- `data.py` — 파일 탐색·로딩, 파일 인벤토리
- `engine.py` — 매칭 / 합산·요율 / 리스크 / 그룹 현금 / 대안 탐색 (규칙 기반, 근거 행 id 포함)
- `workflow.py` — 상태 머신, 역할 권한, 알림, 소명 스레드, 감사 로그(SQLite 트리거로 수정·삭제 차단)
- `app.py`, `templates/` — 화면 (요청함, 새 요청, 요청 상세, 알림, 감사 로그·CSV, 데이터 연결)
