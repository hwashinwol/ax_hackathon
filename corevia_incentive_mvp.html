관련 거래처 판매장려금 결재 시스템

영업팀은 A대리점과 B쇼핑몰을 한 사장님의 관련 거래처로 보고 실적 합산 장려금을 요청하고, 재무·내부감시팀은 서류상 명의가 달라 배임 리스크를 이유로 지급을 막습니다. 이 시스템은 AI가 동일 지배구조 근거를 점수로 제시하고, 합산 실적·품질 리스크·현금 사정을 순서대로 판단해 결재와 대안까지 한 화면 흐름으로 처리합니다.

화면의 거래처·금액·점수는 모두 예시 데이터입니다. 실제 운영 데이터와 외부 인사이트는 추후 업로드 화면(S0)으로 입력합니다. 입력 예정 표시는 값이 아직 정해지지 않은 파라미터입니다.

1 · 처리 구조

기본 4단계와 두 개의 분기

① 확인

AI 거래처 매칭

대표자명·연락처·사업장 주소·등록 IP·정산계좌로 동일 지배구조 확률을 계산하고 근거를 함께 보여줍니다.

② 판단

실적 합산·조건 검증

그룹 누적 매출을 합산해 지급 기준(Threshold) 초과 여부와 장려금액을 자동 계산합니다.

③ 승인 요청

재무·내부감시 결재

매칭 확률과 근거, 합산 실적을 담은 결재 팝업을 재무팀과 내부감시팀에 순차 발송합니다.

④ 처리

지급 / 상태 변경

승인되면 현금 지급, 거절되면 사유에 맞는 대안 프로세스로 넘깁니다. 모든 판단은 감사 로그에 남습니다.

분기 A · 나만의 확장

악성 품질 클레임 거래처 자동 보류

실적을 충족해도 최근 기간 내 품질팀이 '악의적'으로 판정한 클레임이 3회 이상이면 결재로 넘기지 않고 보류(Pending) 처리합니다. 영업팀·품질팀에 소명 요청 알림을 보내고, 품질팀이 해제해야 결재가 재개됩니다.

분기 B · 다른 부서 영향

현금 거절 시 Masil 재고 할인 대체

재무팀이 그룹 현금흐름 악화로 현금 지급을 거절하면, AI가 동일 금액을 유통 자회사 Masil의 다음 발주에 재고 할인(Credit)으로 반영하는 안을 제안합니다. 영업·재무 양측이 수락하면 지급 계획이 바뀝니다.

      4 · 화면 목록

      MVP에 필요한 화면 8개

      S0 · 데이터 연결

      데이터 업로드

      운영 데이터·외부 인사이트를 넣는 곳. 지금은 비어 있고 추후 입력.

      • 거래처 마스터 CSV/Excel 업로드
      • 매출 실적(월별) 업로드
      • 품질 클레임 이력 업로드
      • 컬럼 매핑 · 검증 결과
      S1 · 요청함

      장려금 요청 목록

      역할별로 내가 처리할 건을 상태 필터로 보여줍니다.

      • 상태 필 · 요청금액 · 경과일
      • 보류/결재대기 배지
      • 새 요청 버튼(영업)
      S2 · 새 요청

      요청 작성

      영업팀이 기준 거래처와 정산 기간을 고르고 매칭을 실행합니다.

      • 거래처 검색 · 기간 선택
      • 관련 거래처 후보 직접 추가
      • 요청 사유 메모
      S3 · 매칭 결과

      관련 거래처 그룹

      매칭 확률과 신호별 근거. 내부감시팀이 근거를 그대로 보고 판단합니다.

      • 신호별 가중치 막대
      • 그룹 구성 거래처 표
      • 그룹 확정 / 제외
      S4 · 실적 검증

      합산 실적과 기준선

      거래처별 매출을 쌓은 막대와 기준선, 장려금 계산식.

      • 개별 vs 합산 비교
      • 장려금 = 합산 × 요율
      • 리스크 검사 결과 체크리스트
      S5 · 결재

      승인 팝업

      재무 → 내부감시 순차 결재. 거절은 사유 코드 필수.

      • 요약 카드(확률·실적·금액)
      • 승인 / 거절 + 사유 선택
      • 현금흐름 지표 참고 영역
      S6 · 보류·대안

      예외 처리

      보류 경고와 소명 스레드, 현금 거절 시 대체 지급 제안.

      • 클레임 이력 표 · 소명 제출
      • 대안 카드(크레딧 조건)
      • 영업·재무 각각 수락
      S7 · 감사 로그

      판단 이력

      매칭 근거, 계산값, 결재자, 시각을 변경 불가 기록으로 남깁니다.

      • 요청 건별 타임라인
      • CSV 내보내기(내부 감사용)

      8 · 범위

      MVP에서 만드는 것과 미루는 것

      MVP 포함

      • S0~S7 화면, 역할 전환으로 시연
      • 규칙 기반 매칭 점수 + 신호별 근거 표시
      • 합산 실적·장려금 자동 계산
      • 악성 클레임 자동 보류 + 영업·품질 알림
      • 재무 → 내부감시 2단계 결재, 사유 코드
      • 현금 부족 거절 시 Masil 크레딧 대안 제안·수락
      • 감사 로그 (변경 불가 기록)

      MVP 이후

      • 학습 기반 매칭 모델(가중치 자동 조정)
      • Masil 발주 시스템 실시간 API 연동 (MVP는 수기 확인)
      • 지주사(Aurora Holdings) 고액 결재선
      • 그룹 현금흐름 예측과 지급 시점 추천
      • 메신저·메일 알림 연동 (MVP는 앱 내 알림)
